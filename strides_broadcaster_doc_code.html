Dạng 1: Tính Toán Dung Lượng Bộ Nhớ & Strides Của Mảng

💡 Hướng dẫn Lý thuyết & Công thức tính

Mảng ndarray lưu dữ liệu liên tục trong bộ nhớ RAM kèm theo các thông tin quản lý (Metadata):

  • Kích thước 1 phần tử (itemsize): Xác định bởi dtype (VD: int8/uint8 = 1 byte; int32/float32 = 4 bytes; int64/float64 = 8 bytes).
  • Tổng số phần tử (size): N = Tích các chiều trong shape.
  • Dung lượng vùng dữ liệu thô (nbytes): nbytes = size × itemsize.
  • Strides (Bước nhảy bộ nhớ): Là một tuple chứa số byte cần di chuyển trong bộ nhớ để tiến 1 bước dọc theo chiều (axis) tương ứng.
    • Đối với mảng lưu theo hàng chuẩn (C-contiguous / C-order) kích thước (d₀, d₁, ..., dₖ₋₁):
    • stride[k-1] = itemsize
    • stride[i] = stride[i+1] × d[i+1]

Bài 1.1: Mảng 2D cơ bản

Cho mảng NumPy A = np.zeros((4, 5), dtype=np.float64) được khởi tạo theo C-order.

Yêu cầu: Tính A.itemsize, A.size, A.nbytes và A.strides.

Lời giải:

  • dtype = float64 → mỗi phần tử chiếm 64 / 8 = 8 bytes → itemsize = 8.
  • shape = (4, 5) → size = 4 * 5 = 20 phần tử.
  • nbytes = size * itemsize = 20 * 8 = 160 bytes.
  • Strides:
    • Trục 1 (cột): Nhảy 1 phần tử tốn 8 bytes → stride[1] = 8.
    • Trục 0 (hàng): Nhảy 1 hàng (qua 5 cột) tốn 5 × 8 = 40 bytes → stride[0] = 40.

Đáp án: itemsize = 8, size = 20, nbytes = 160 bytes, strides = (40, 8).

Bài 1.2: Mảng 3D C-order

Cho mảng NumPy B = np.ones((2, 3, 4), dtype=np.int32).

Yêu cầu: Tính dung lượng dữ liệu nbytes và bộ strides của mảng B.

Lời giải:

  • dtype = int32 → itemsize = 4 bytes.
  • size = 2 * 3 * 4 = 24 phần tử.
  • nbytes = 24 * 4 = 96 bytes.
  • Strides (C-order):
    • Axis 2: 4 bytes.
    • Axis 1: 4 phần tử × 4 bytes = 16 bytes.
    • Axis 0: 3 × 16 = 48 bytes.

Đáp án: nbytes = 96 bytes, strides = (48, 16, 4).

Bài 1.3: Chuyển đổi Shape (Reshape)

Cho mảng x = np.arange(12, dtype=np.int64). Thực hiện y = x.reshape(3, 4).

Yêu cầu: Việc reshape có làm thay đổi nbytes của dữ liệu không? Xác định strides của x và y.

Lời giải:

  • int64 có itemsize = 8 bytes. Cả x và y đều chia sẻ chung vùng bộ nhớ 12 phần tử → nbytes = 12 * 8 = 96 bytes (không thay đổi).
  • x.shape = (12,) → x.strides = (8,).
  • y.shape = (3, 4) → y.strides = (4*8, 8) = (32, 8).

Đáp án: Dung lượng không đổi (96 bytes); x.strides = (8,), y.strides = (32, 8).

Bài 1.4: Thao tác Chuyển vị (Transpose)

Cho A = np.zeros((3, 5), dtype=np.float32) và T = A.T (chuyển vị của A).

Yêu cầu: Tính strides của A và T. Giải thích vì sao T không làm copy dữ liệu.

Lời giải:

  • float32 → itemsize = 4 bytes.
  • A.shape = (3, 5) → A.strides = (5*4, 4) = (20, 4).
  • Khi gọi A.T, NumPy chỉ cần hoán đổi shape thành (5, 3) và đảo ngược bộ strides thành (4, 20). Vì chỉ sửa metadata nên không cần cấp phát lại bộ nhớ dữ liệu (View).

Đáp án: A.strides = (20, 4); T.strides = (4, 20).

Bài 1.5: Slicing và Bước nhảy (Step > 1)

Cho arr = np.arange(20, dtype=np.int8). Tạo mảng con sub = arr[::2].

Yêu cầu: Tính sub.size, sub.nbytes và sub.strides.

Lời giải:

  • dtype = int8 → itemsize = 1 byte.
  • Lấy bước 2 → sub có 10 phần tử → sub.size = 10.
  • sub.nbytes = 10 * 1 = 10 bytes.
  • Bước nhảy của slice là 2 → mỗi bước dịch chuyển trong RAM tốn 2 × 1 = 2 bytes.

Đáp án: sub.size = 10, sub.nbytes = 10, sub.strides = (2,).

Bài 1.6: Fortran-order (F-contiguous)

Cho mảng F = np.zeros((3, 4), dtype=np.int64, order='F').

Yêu cầu: Tính F.strides và so sánh với mảng lưu theo C-order cùng kích thước.

Lời giải:

  • itemsize = 8 bytes. Mảng Fortran-order lưu theo cột (column-major).
  • Trục 0 (hàng): Tiến 1 phần tử trong cùng cột tốn 8 bytes → stride[0] = 8.
  • Trục 1 (cột): Tiến 1 cột (qua 3 hàng) tốn 3 × 8 = 24 bytes → stride[1] = 24.
  • (Nếu là C-order thì strides = (32, 8)).

Đáp án: F.strides = (8, 24).

Bài 1.7: Mảng 4D trong Deep Learning

Trong xử lý ảnh, một batch dữ liệu có shape = (32, 64, 64, 3) với kiểu dữ liệu np.float32 (32 ảnh RGB 64x64).

Yêu cầu: Tính tổng dung lượng RAM (tính theo Megabytes - MB) chứa dữ liệu thô này và bộ strides của mảng.

Lời giải:

  • itemsize = 4 bytes.
  • size = 32 * 64 * 64 * 3 = 393,216 phần tử.
  • nbytes = 393,216 * 4 = 1,572,864 bytes ≈ 1.5 MB.
  • Strides:
    • s[3] = 4 bytes
    • s[2] = 3 × 4 = 12 bytes
    • s[1] = 64 × 12 = 768 bytes
    • s[0] = 64 × 768 = 49,152 bytes

Đáp án: Dung lượng ≈ 1.5 MB (1,572,864 bytes); strides = (49152, 768, 12, 4).

Bài 1.8: So sánh List vs ndarray

Giả sử ta cần lưu 1.000.000 số nguyên 64-bit. So sánh dung lượng bộ nhớ dữ liệu khi dùng np.array(..., dtype=np.int64) và danh sách chuẩn của Python list (giả thiết mỗi PyObject_Int tốn 28 bytes + 8 bytes tham chiếu trong list).

Yêu cầu: Tính tỉ lệ chênh lệch bộ nhớ xấp xỉ.

Lời giải:

  • Với NumPy ndarray: 1.000.000 × 8 bytes = 8.000.000 bytes ≈ 7.63 MB.
  • Với Python list: Mỗi phần tử gồm pointer (8 bytes) + PyObject (28 bytes) = 36 bytes → 36.000.000 bytes ≈ 34.33 MB.
  • Tỉ lệ: Python List tốn gấp ≈ 4.5 lần so với NumPy array.

Đáp án: NumPy tốn 8 MB; Python List tốn ≈ 36 MB (Gấp 4.5 lần).

Bài 1.9: Strides khi đảo ngược mảng (Reverse Slicing)

Cho arr = np.array([10, 20, 30, 40, 50], dtype=np.int64). Tạo rev = arr[::-1].

Yêu cầu: Xác định rev.strides và nêu ý nghĩa số âm trong strides.

Lời giải:

  • itemsize = 8 bytes.
  • Khi dùng bước slice là -1, trong bộ nhớ pointer sẽ lùi lại thay vì tiến lên.
  • Do đó, rev.strides = (-8,). Số âm nghĩa là để sang phần tử kế tiếp của mảng view, ta phải dịch con trỏ lùi về trước trong RAM 8 bytes.

Đáp án: rev.strides = (-8,).

Bài 1.10: Dummy Dimension và Stride bằng 0

Dùng kĩ thuật stride_tricks để mở rộng mảng a = np.array([1, 2, 3], dtype=np.int64) thành mảng 2D kích thước (4, 3) mà không tốn thêm bộ nhớ bằng cách đặt stride[0] = 0.

Yêu cầu: Dung lượng bộ nhớ thực tế tiêu tốn là bao nhiêu? Giải thích stride = 0.

Lời giải:

  • Mảng ban đầu chỉ có 3 phần tử int64 → 3 × 8 = 24 bytes.
  • Khi thiết lập stride[0] = 0 và stride[1] = 8 với shape = (4, 3), bất kỳ khi nào chỉ số hàng thay đổi, con trỏ dịch chuyển 0 byte (tức là dùng lại đúng 3 phần tử đó cho cả 4 hàng).
  • Dung lượng dữ liệu tiêu tốn thực tế giữ nguyên là 24 bytes.

Đáp án: Dung lượng thực tế tiêu tốn = 24 bytes. Stride = 0 có nghĩa là các hàng trỏ cùng vào một vùng nhớ.

Dạng 2: Lý Thuyết Broadcasting & Bài Tập Áp Dụng

💡 Lý thuyết Broadcasting trong NumPy

Broadcasting là cơ chế cho phép NumPy thực hiện các phép toán đại số trên các mảng có kích thước (shape) khác nhau mà không cần sao chép dữ liệu không cần thiết.

Quy tắc Broadcasting (Thực hiện từ phải sang trái - Trailing dimensions):

  1. Nếu hai mảng khác số chiều, mảng có ít chiều hơn sẽ được thêm các chiều có kích thước bằng 1 vào bên trái.
  2. Hai chiều được coi là tương thích (compatible) nếu:
    • Kích thước của chúng bằng nhau, HOẶC
    • Một trong hai chiều có kích thước bằng 1.

Nếu hai điều kiện trên thỏa mãn ở tất cả các chiều, mảng sẽ broadcast thành công. Nếu không, NumPy sẽ báo lỗi ValueError: operands could not be broadcast together.

Bài 2.1: Kiểm tra tính tương thích 2D & 1D

Cho A.shape = (3, 4) và B.shape = (4,).

Yêu cầu: Phép tính A + B có hợp lệ không? Nếu có, kích thước kết quả là bao nhiêu?

Lời giải:

  • Căn chỉnh chiều từ phải sang trái:
    A: (3, 4)
    B: (1, 4) (Thêm 1 vào bên trái B)
  • So sánh: Axis 1 (4 == 4), Axis 0 (3 tương thích với 1).

Đáp án: Hợp lệ. Shape kết quả là (3, 4).

Bài 2.2: Báo lỗi Broadcasting

Cho A.shape = (3, 4) và B.shape = (3,).

Yêu cầu: Phép tính A + B có thực hiện được không? Giải thích vì sao và đề xuất cách sửa.

Lời giải:

  • Căn chỉnh:
    A: (3, 4)
    B: (1, 3) (B tự động chèn 1 sang trái)
  • So sánh trục cuối: 4 ≠ 3 (Không có cái nào bằng 1) → Báo lỗi ValueError.
  • Sửa: Đổi shape B thành (3, 1) bằng B[:, np.newaxis]. Lúc đó (3, 4) + (3, 1) -> (3, 4).

Đáp án: Không thực hiện được. Cần đổi B thành shape (3, 1).

Bài 2.3: Ma trận Outer Product đơn giản

Cho a = np.array([1, 2, 3]) (shape (3,)) và b = np.array([10, 20]) (shape (2,)).

Yêu cầu: Dùng broadcasting để tạo ma trận tích kích thước (3, 2).

Lời giải:

  • Biến đổi a thành shape (3, 1) bằng a[:, np.newaxis].
  • b có shape (2,) bọc thành (1, 2).
  • Phép nhân a[:, np.newaxis] * b có shape (3, 1) * (1, 2) -> (3, 2).
  • Kết quả: [[10, 20], [20, 40], [30, 60]].

Đáp án: Code: a[:, None] * b. Result shape (3, 2).

Bài 2.4: Phức tạp hóa 3D

Cho 3 mảng: X.shape = (1, 5, 1), Y.shape = (4, 1, 1), Z.shape = (3,).

Yêu cầu: Kích thước mảng kết quả của X + Y + Z là bao nhiêu?

Lời giải:

  • Căn chỉnh các shape:
    X: (1, 5, 1)
    Y: (4, 1, 1)
    Z: (1, 1, 3)
  • Kết hợp từng trục: max(1, 4, 1) = 4; max(5, 1, 1) = 5; max(1, 1, 3) = 3.

Đáp án: Kích thước kết quả là (4, 5, 3).

Bài 2.5: Chuẩn hóa dữ liệu (Column-wise Normalization)

Cho ma trận dữ liệu Data.shape = (100, 10) (100 mẫu, 10 đặc trưng). Ta tính trung bình mỗi đặc trưng được mean = Data.mean(axis=0).

Yêu cầu: Phép tính Data - mean hoạt động nhờ broadcasting như thế nào?

Lời giải:

  • mean tính theo axis=0 nên có shape là (10,).
  • Khi thực hiện Data - mean:
    Data: (100, 10)
    mean: ( 1, 10)
  • Mảng mean được broadcast tự động dọc theo 100 hàng, trừ giá trị trung bình tương ứng của từng cột.

Đáp án: Phép trừ hợp lệ, shape kết quả (100, 10).

Bài 2.6: Row-wise Normalization

Cho Data.shape = (100, 10). Ta muốn trừ đi giá trị trung bình của từng hàng row_mean = Data.mean(axis=1).

Yêu cầu: Viết biểu thức chuẩn hóa đúng (tránh lỗi shape mismatch).

Lời giải:

  • row_mean = Data.mean(axis=1) có shape (100,).
  • Nếu viết Data - row_mean: (100, 10) vs (1, 100) → Lỗi!
  • Cần biến đổi row_mean về 2D có shape (100, 1): dùng Data.mean(axis=1, keepdims=True) hoặc row_mean[:, np.newaxis].

Đáp án: Code đúng: Data - Data.mean(axis=1, keepdims=True).

Bài 2.7: Tải ảnh RGB

Một bức ảnh RGB có shape (256, 256, 3). Ta muốn nhân hệ số chỉnh màu cho 3 kênh màu R, G, B tương ứng với mảng scale = np.array([1.2, 0.9, 1.1]).

Yêu cầu: Phép tính img * scale có hợp lệ không? Giải thích.

Lời giải:

  • img.shape = (256, 256, 3)
  • scale.shape = (3,) → được bổ sung 1 thành (1, 1, 3).
  • Khớp chiều cuối 3 == 3. scale sẽ nhân tương ứng vào tất cả các pixel.

Đáp án: Hợp lệ. Shape kết quả là (256, 256, 3).

Bài 2.8: Ma trận khoảng cách Euclidean (Pairwise Distance)

Cho mảng A chứa 3 điểm 1D: A = np.array([1, 4, 10]) (shape (3,)).

Yêu cầu: Dùng broadcasting tạo ma trận khoảng cách D_ij = |A_i - A_j|.

Lời giải:

  • Biến đổi A thành cột A_col = A[:, np.newaxis] (shape (3, 1)).
  • Thực hiện phép trừ broadcast: D = np.abs(A[:, np.newaxis] - A).
  • (3, 1) - (1, 3) -> (3, 3).

Đáp án: np.abs(A[:, None] - A).

Bài 2.9: Scalar Broadcast

Cho m = np.ones((5, 5), dtype=np.int32) và số vô hướng s = 5.

Yêu cầu: Số vô hướng được coi có shape là bao nhiêu khi broadcast với m?

Lời giải:

  • Số vô hướng (scalar) có shape là tuple rỗng ().
  • Nó được tự động pad thêm các chiều 1 thành (1, 1) và lấp đầy toàn bộ các phần tử của m.

Đáp án: Scalar có shape (), broadcast tự do với mọi mảng.

Bài 2.10: Tìm lỗi sai phức tạp

Phép toán nào sau đây gây ra lỗi ValueError?

a) np.zeros((2, 1, 4)) + np.zeros((3, 4))

b) np.zeros((2, 1, 4)) + np.zeros((3, 1))

Lời giải:

  • Trường hợp a: (2, 1, 4) và (1, 3, 4). Trục 1: 1 vs 3 (ok), Trục 2: 4 vs 4 (ok) → Thành công: (2, 3, 4).
  • Trường hợp b: (2, 1, 4) và (1, 3, 1). Trục 0: 2 vs 1 (ok), Trục 1: 1 vs 3 (ok), Trục 2: 4 vs 1 (ok) → Thành công: (2, 3, 4).
  • Cả 2 đều KHÔNG lỗi!

Đáp án: Cả 2 phép toán đều hợp lệ và cho ra shape (2, 3, 4).

Dạng 3: Đọc Code NumPy & Trắc Nghiệm "Xoáy" (10 Câu)

Chọn đáp án đúng nhất cho từng đoạn code dưới đây. Hệ thống sẽ chấm điểm và hiển thị giải thích chi tiết bẫy ngay lập tức.

Câu 1: Tràn số (Integer Overflow) với dtype hẹp

import numpy as np
a = np.array([100, 120, 127], dtype=np.int8)
b = a + 10
print(b[2])
  • A. 137
  • B. -119
  • C. Lỗi OverflowError
  • D. 127
Giải thích Bẫy: Trong NumPy, int8 biểu diễn số nguyên có dấu từ -128 đến 127. Khi lấy 127 + 10 = 137, nó bị tràn số quay vòng (wrap-around) trong hệ nhị phân 8-bit: 137 - 256 = -119. Khác với Python thuần tự tăng kích thước bit, NumPy giữ nguyên dtype ngoại trừ khi dùng ufunc ép kiểu.

Câu 2: Slicing (View) vs Advanced Indexing (Copy)

import numpy as np
arr = np.array([10, 20, 30, 40, 50])
v1 = arr[1:4]
v2 = arr[[1, 2, 3]]
v1[0] = 99
v2[1] = 88
print(arr)
  • A. [10, 99, 88, 40, 50]
  • B. [10, 99, 30, 40, 50]
  • C. [10, 20, 30, 40, 50]
  • D. [10, 99, 88, 99, 50]
Giải thích Bẫy: v1 = arr[1:4] là Basic Slicing → tạo View (chia sẻ bộ nhớ với arr). Khi đổi v1[0] = 99, arr[1] đổi thành 99. Trong khi đó, v2 = arr[[1, 2, 3]] dùng Fancy Indexing (dùng list chỉ số) → tạo Copy hoàn toàn mới. Thay đổi trên v2 không ảnh hưởng arr!

Câu 3: Phép gán inplace operator (+=) vs (+)

import numpy as np
a = np.array([1, 2, 3], dtype=np.float64)
b = a
a += 1
c = a + 1
print(b, a is b)
  • A. [1. 2. 3.] False
  • B. [2. 3. 4.] False
  • C. [2. 3. 4.] True
  • D. [3. 4. 5.] True
Giải thích Bẫy: Toán tử a += 1 sửa trực tiếp dữ liệu trên vùng nhớ hiện tại (in-place operation). Vì b trỏ cùng mảng với a nên b cũng thay đổi thành [2., 3., 4.]. Biểu thức a + 1 sau đó tạo ra một mảng mới gắn cho c nhưng không làm đổi a. a is b trả về True.

Câu 4: Chuyển kiểu dtype trước hay sau phép tính

import numpy as np
x = np.array([100, 100], dtype=np.int8)
res1 = (x * 2).astype(np.int16)
res2 = x.astype(np.int16) * 2
print(res1[0], res2[0])
  • A. 200 200
  • B. -56 200
  • C. -56 -56
  • D. Lỗi ValueError
Giải thích Bẫy: Trong res1, phép nhân x * 2 chạy trước trên kiểu int8. 100 × 2 = 200 tràn số 200 - 256 = -56. Sau đó mới cast sang int16 thì đã muộn (-56). Với res2, x được đổi sang int16 trước nên phép nhân ra kết quả 200 chính xác.

Câu 5: Cạm bẫy Axis trong ufunc (sum)

import numpy as np
m = np.array([[1, 2, 3],
              [4, 5, 6]])
print(m.sum(axis=0))
  • A. [6, 15]
  • B. [5, 7, 9]
  • C. 21
  • D. [[5, 7, 9]]
Giải thích Bẫy: axis=0 trong NumPy là tính tổng **dọc theo các hàng** (tức là cộng dồn các phần tử ở từng cột lại với nhau): [1+4, 2+5, 3+6] = [5, 7, 9]. Rất nhiều bạn nhầm axis=0 là cộng theo chiều ngang từng hàng!

Câu 6: Boolean Masking & Shape collapse

import numpy as np
A = np.array([[1, 2], [3, 4]])
mask = A > 2
print(A[mask].shape)
  • A. (2, 2)
  • B. (1, 2)
  • C. (2,)
  • D. (2, 1)
Giải thích Bẫy: Lọc dữ liệu bằng Boolean Mask (như A[A > 2]) luôn luôn làm "phẳng" (flatten) kết quả về mảng 1D, vì số lượng phần tử thỏa mãn điều kiện ở mỗi hàng/cột có thể không đồng đều. Do đó kết quả thu được mảng [3, 4] có shape (2,).

Câu 7: Broadcasting với newaxis

import numpy as np
a = np.array([1, 2, 3])
b = np.array([10, 20])
res = a[:, np.newaxis] + b
print(res.shape)
  • A. (3, 2)
  • B. (2, 3)
  • C. (3,)
  • D. Báo lỗi ValueError
Giải thích Bẫy: a[:, np.newaxis] biến a từ (3,) thành (3, 1). Mảng b có shape (2,) được coi là (1, 2). Broadcast (3, 1) + (1, 2) ra kết quả (3, 2).

Câu 8: Strides sau khi Reshape vs Transpose

import numpy as np
x = np.arange(6, dtype=np.int32).reshape(2, 3)
y = x.T
print(x.strides, y.strides)
  • A. (12, 4) và (12, 4)
  • B. (12, 4) và (4, 12)
  • C. (24, 8) và (8, 24)
  • D. (4, 12) và (12, 4)
Giải thích Bẫy: int32 có itemsize = 4 bytes.
x.shape = (2, 3) → x.strides = (3*4, 4) = (12, 4).
Khi chuyển vị y = x.T, shape đổi thành (3, 2) và bộ strides chỉ việc đảo ngược lại thành (4, 12).

Câu 9: Bẫy chia cho 0 trong NumPy khác với Python

import numpy as np
a = np.array([0, 1], dtype=np.float64)
b = np.array([0, 2], dtype=np.float64)
c = a / b
print(c[0])
  • A. ZeroDivisionError
  • B. 0.0
  • C. nan
  • D. inf
Giải thích Bẫy: Phép chia 0/0 trong Python thuần bắn lỗi ZeroDivisionError. Tuy nhiên trong NumPy trên số thực (float), nó sẽ phát ra RuntimeWarning và trả về giá trị đặc biệt np.nan (Not a Number). Nếu là 1/0 thì trả về np.inf.

Câu 10: Copy sâu và View với Fancy Indexing

import numpy as np
x = np.zeros((3, 3))
x[[0, 1], [0, 1]] = 5
print(np.count_nonzero(x))
  • A. 4
  • B. 2
  • C. 9
  • D. 0
Giải thích Bẫy: Cú pháp x[[0, 1], [0, 1]] = 5 chọn các phần tử tại vị trí tọa độ cặp (0,0) và (1,1) (chứ không phải chọn cả ma trận con 2x2). Do đó chỉ có 2 vị trí đường chéo được gán bằng 5, tổng số phần tử khác 0 là 2.
