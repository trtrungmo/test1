Lý thuyết & Bài tập: Quản lý môi trường Python

Chào em, thầy đã nhận được yêu cầu. Dành cho các bạn "mất gốc", việc hiểu rõ cách Python quản lý môi trường ảo (virtual environment) và các thư viện (packages) là nền tảng cực kỳ quan trọng để code không bị lỗi vặt. Em hãy đọc kỹ lý thuyết thầy tóm tắt dưới đây nhé!

Tóm tắt Lý thuyết Trọng tâm

  • Môi trường ảo (venv): Giúp cô lập các thư viện của từng dự án. Lệnh python -m venv .venv sẽ tạo môi trường ảo bằng chính phiên bản Python đang chạy lệnh đó. Công cụ này không biết tự tải hay tự đổi phiên bản Python.
  • File requirements.txt: Chứa danh sách các thư viện (packages) và phiên bản của chúng (tạo bằng pip freeze > requirements.txt). File này không lưu phiên bản Python.
  • File .python-version: Là file text chỉ định phiên bản Python cần dùng, thường được đọc bởi các công cụ quản lý phiên bản (như pyenv). Công cụ pip hay venv mặc định không quan tâm đến file này.
  • pip: Là công cụ cài đặt thư viện (packages). Khi em chạy pip install, nó chỉ cài thư viện vào môi trường hiện tại đang được kích hoạt (activate). Nếu em quên activate, thư viện sẽ bị cài vào Python hệ thống. Cài thư viện không đồng nghĩa với việc nâng cấp phiên bản Python.
  • pyenv: Dùng để tải và quản lý nhiều phiên bản Python trên cùng một máy tính. Nó khác với venv (chỉ quản lý thư viện của một dự án).
