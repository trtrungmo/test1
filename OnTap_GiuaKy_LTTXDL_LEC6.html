Phần 3: SQL và DuckDB

Đưa sức mạnh truy vấn OLAP vào trực tiếp môi trường phân tích dữ liệu Python.

1 Lý thuyết tổng quan

DuckDB là một hệ quản trị cơ sở dữ liệu quan hệ (RDBMS) hoạt động theo cơ chế in-process (chạy nhúng trực tiếp vào tiến trình đang chạy). Nó được thiết kế tối ưu hoá cho các tác vụ phân tích dữ liệu phân tích (OLAP).

Thay vì phải cài đặt hay duy trì một database server cồng kềnh qua cổng mạng, DuckDB chạy ngay bên trong kernel Colab/Jupyter. Điều này cho phép bạn dùng thẳng cú pháp SQL mạnh mẽ để truy xuất dữ liệu từ các biến DataFrame hay các file (như Parquet, CSV) với tốc độ thực thi vượt trội nhờ cơ chế vector hóa (vectorized execution).

2 LƯU Ý (Notice)

  • Kết nối ẩn tới Pandas: DuckDB tự động quét môi trường của bạn. Nếu bạn đã định nghĩa biến df hay santiago_listings trong Colab, bạn có thể SELECT FROM santiago_listings ngay lập tức mà không cần lệnh import phức tạp.
  • Dữ liệu trả về (Data Casting): Lệnh của DuckDB luôn trả về một object kiểu DuckDB Relation. Để tương thích với các bước xử lý dữ liệu tiếp theo, bạn bắt buộc phải gọi hàm .df() ở cuối câu lệnh để parse nó về pandas.DataFrame.
  • Quy tắc đặt tên: Các biến DataFrame đem vào môi trường SQL không được chứa ký tự trắng hoặc các ký hiệu đặc biệt. Hãy sử dụng dấu gạch dưới (snake_case) theo đúng chuẩn.

3 Các hàm chuyên dụng

duckdb.sql()

Thực thi một chuỗi câu lệnh SQL. Hỗ trợ đầy đủ các thao tác GROUP BY, JOIN, WINDOW FUNCTIONS trực tiếp trên biến DataFrame đang chạy.

duckdb.read_parquet()

Truy xuất dữ liệu trực tiếp từ file Parquet cực nhanh mà không cần load toàn bộ file vào RAM trước, tối ưu khả năng nén bộ nhớ.

4 Ví dụ thao tác (Colab / Jupyter) 

import pandas as pd
import duckdb

# 1. Khởi tạo dữ liệu trực tiếp
cho_o = pd.DataFrame({
    'id': ['001', '002', '003', '004', '005'],
    'khu': ['A', 'B', 'A', 'B', 'A'],
    'gia': [100.0, 80.0, 200.0, 120.0, 50.0]
})

# 2. Truy vấn thẳng vào biến 'cho_o' vừa tạo
query = """
    SELECT khu, AVG(gia) AS gia_trung_binh
    FROM cho_o
    WHERE gia >= 80
    GROUP BY khu
"""

# 3. Đưa kết quả về lại Pandas DataFrame
ket_qua = duckdb.sql(query).df()
print(ket_qua)

5 Thực hành

Hoàn thiện các đoạn lệnh SQL sau (đều dựa trên dữ liệu bảng cho_o ở trên). Nhấn vào "Xem đáp án" để mở code ẩn.

💻 Yêu cầu 1: Lọc và Sắp xếp

Lọc ra danh sách các phòng thuộc khu 'A', sau đó sắp xếp theo giá giảm dần. Xuất ra định dạng DataFrame.

▶ Xem đáp án code 
cau_1_df = duckdb.sql("""
    SELECT * 
    FROM cho_o 
    WHERE khu = 'A' 
    ORDER BY gia DESC
""").df()

print(cau_1_df)

💻 Yêu cầu 2: Hàm tổng hợp (Aggregation)

Sử dụng DuckDB để đếm tổng số lượng chỗ ở và tính tổng doanh thu (tổng giá) cho toàn bộ dữ liệu cho_o.

▶ Xem đáp án code 
cau_2_df = duckdb.sql("""
    SELECT 
        COUNT(id) AS tong_so_luong, 
        SUM(gia) AS tong_doanh_thu
    FROM cho_o
""").df()

print(cau_2_df)

💻 Yêu cầu 3: Truy vấn chéo từ ổ đĩa

Thay vì lấy từ biến bộ nhớ, hãy viết lệnh DuckDB SQL đọc trực tiếp dữ liệu từ đường dẫn file gốc 'data/processed/listings.parquet', giới hạn hiển thị chỉ 5 dòng đầu tiên (LIMIT).

▶ Xem đáp án code 
cau_3_df = duckdb.sql("""
    SELECT * 
    FROM 'data/processed/listings.parquet'
    LIMIT 5
""").df()

print(cau_3_df)
