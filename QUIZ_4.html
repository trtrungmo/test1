1. Đọc tệp CSV với Module `csv`

Sử dụng `csv.DictReader` giúp đọc từng dòng dưới dạng Dictionary (tên cột là key, giá trị là value):

import csv
with open("data.csv", encoding="utf-8") as f:
  rows = list(csv.DictReader(f))
  for r in rows:
    print(r["ma"], r["so_dem"])

⚠️ Chú ý quan trọng: Dữ liệu đọc từ file CSV mặc định là kiểu chuỗi (string) dù trong file là số!

⚡

2. Sắp xếp với `sorted()` & `lambda`

Dùng tham số `key` kết hợp hàm ẩn `lambda` để chỉ định cột sắp xếp dữ liệu phức tạp:

# Sắp xếp giảm dần (reverse=True) theo khóa "so_dem"
dai = sorted(rows, key=lambda r: r["so_dem"], reverse=True)

# Lấy phần tử đứng đầu tiên sau khi sắp xếp
print(dai[0]["ma"])

🚨 Lỗi bẫy kinh điển: Nếu `so_dem` là chuỗi ("40", "5", "9"), Python sắp xếp theo bảng chữ cái ("9" > "40"). Phải ép kiểu `int(r["so_dem"])` nếu muốn so sánh số học!

📖

3. Thao tác với Dictionary

Dictionary lưu trữ cặp khóa-giá trị (key-value):

di={ "ma": "L1", "so_dem": 40 }
print(di.keys()) # dict_keys(['ma', 'so_dem'])
print(di.values()) # dict_values(['L1', 40])
di.get("sai", 0) # Tránh lỗi KeyError, trả về 0 nếu không thấy
💡

4. List, Vòng lặp & Ép kiểu

Các hàm toán học cơ bản áp dụng trên danh sách:

lst = [10, 20, 30]
print(sum(lst)) # 60
print(max(lst)) # 30
print(len(lst)) # 3
